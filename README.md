# DevTool

DevTool is a self-hosting engineering control plane for local development, AI agents, CI/CD, and enterprise development environments.

The repository is being designed around two documents:

- [Product Design](docs/product-design.md)
- [Implementation Design](docs/implementation-design.md)

The central rule is simple:

> One engineering control plane, one project-facing command surface, and no project workflow duplicated across local scripts, agents, or CI.

DevTool is intended to serve projects such as PhotoWaypoint, BlogCTL, GoTiny, DOWNKIT, and DevTool itself.
